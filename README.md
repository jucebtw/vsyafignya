Тут есть:
- папка `empty-stuff/` со ~100 000 абсолютно пустых файлов


### Как со всем этим попрощаться

Снести мусор:
```bash
rm -rf empty-stuff
```

Снести все шуточные ветки на удалёнке:
```bash
git ls-remote --heads origin 'cursor/*' | awk '{print $2}' | sed 's#refs/heads/##' | xargs -P8 -n50 git push origin --delete
```

Или просто удалить весь репозиторий в Settings → Danger Zone → Delete this repository.
